# AGENTS.md

The operating rules for agents working in this repository are in
[`CLAUDE.md`](CLAUDE.md). Read that file before any change; every rule in it
applies to Codex and any other agent the same way.

This file is a regular file rather than a link to `CLAUDE.md` because
Anthropic's plugin directory refuses to validate a repository with a
symbolic link where the plugin loader reads.
